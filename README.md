# Reinforcement Learning: BabyAI Trajectory Analysis

## 📌 Project Overview

This project focuses on Reinforcement Learning (RL) and the analysis of expert trajectories in the BabyAI-FindObjS5 environment. It explores how an intelligent agent interacts with an environment through states, actions, and rewards to understand decision-making and learning behavior.

The project is developed using Python and Jupyter Notebook as part of my Master of Computer Applications (MCA) in Artificial Intelligence.

## 🎯 Project Objectives

- To understand the fundamental concepts of Reinforcement Learning.
- To study agent-environment interactions.
- To explore states, actions, rewards, and policies.
- To analyze expert trajectories and agent behavior.
- To gain practical experience with Python-based Reinforcement Learning experiments.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook
- **Libraries:** NumPy, Pandas, Matplotlib
- **Environment and Data Tools:** Gymnasium, MiniGrid, Minari *(where used in the project)*
